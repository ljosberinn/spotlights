Spotlights allows you to pick multiple raid members and create separate frames for them in order to single them out without having to keep track their position in your other frames. The name is coined by Cells (RIP) eponymous feature.

Use `/spotlights options` to configure.

This addon is also an experiment/exploration of AI-based addon development with heavy steering. I've authored multiple addons in the past - the goal of this one to not write a single line of code was achieved. The addon is not perfect, but it's performance is decent and the featureset would've taken me at least 4-6 times as long to write.
