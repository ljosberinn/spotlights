Spotlights allows you to pick multiple raid members and create separate frames for them in order to single them out without having to keep track their position in your other frames. The name is coined by Cells (RIP) eponymous feature.

Use `/spotlights options` to configure.

Features:

- free tracking of as many units you want
- free repositioning
- no performance impact
- allow stracking any custom aura by spell id on friendlies that you want
- improves the built-in Sense Power cooldown tracking by adding missing auras
- as Sense Power is required to work, it will prompt you to enable it when entering a raid
- a suite of customization options for the custom frames in general
- as well as a suite of customization options for Prescience and Sense Power tracking
- preview mode
- drag-drop reordering
- allows adding empty spaces to create visually distinct groups
